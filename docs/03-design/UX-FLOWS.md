# UX FLOWS

## PCAR
Prelim → Work Done → Adjustments → Review → Submit.

## Certification
Open PCAR → Compare → Certify/hold → Approve CCAR → Finance queue.

## Negative Claim
Cumulative entitlement falls below previous certification → negative movement → CCAR → AR credit → future allocation/refund.

## Physical Material
Order → DO/delivery evidence → confirmation → bill/claim.

## Progress Work
Contract/SOC → progress measurement → PCAR → CCAR → bill/credit.
