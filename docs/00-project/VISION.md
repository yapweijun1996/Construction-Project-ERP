# VISION

Status: Approved

Create the clearest public demonstration of how a modern construction ERP should think:

**Project first. Commercial truth second. Documents/accounting follow the business lifecycle.**

A user should answer from one project context:
- contract value and approved changes
- work done
- claimed / certified / billed / collected
- budget / committed / actual / forecast cost
- POC and margin
- retention, AR and closeout exposure

## Principles
1. Project is root context.
2. Construction work is not automatically inventory.
3. Fulfilment method determines workflow.
4. Current-period and cumulative values are separate.
5. Claim, certification, billing and cash are separate stages.
6. Historical corrections are traceable adjustments.
7. Client and subcontract flows mirror where useful.
8. Commercial progress and accounting POC are separate.
9. Public demo must look like five years of real operations.
10. Demo must be offline-capable and resettable.
