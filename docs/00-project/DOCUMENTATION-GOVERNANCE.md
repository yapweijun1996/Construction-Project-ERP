# DOCUMENTATION GOVERNANCE

## Purpose by Document
- VISION: why
- ROADMAP: delivery sequence
- EPIC: large business capability
- SPEC: required behaviour
- DESIGN: interaction/presentation
- BUSINESS RULE: cross-feature invariant
- ADR: decision + rationale
- TASK: concrete implementation unit
- TEST/QA: evidence
- CHANGELOG: completed user-visible changes

## IDs
EPIC-001, SPEC-001, TASK-001, ADR-001, BR-CLAIM-001.

TASKs reference SPECs; they do not redefine them.
